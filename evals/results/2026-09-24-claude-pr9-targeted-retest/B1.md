## Problems found and fixed

**Must-fix**
1. **Keyboard users couldn't sign in.** The "Log in" button was a plain `<div>` (`Login.tsx:8`), so Tab and Enter did nothing. It's now a real form with a submit button.
2. **A failed login could leave a fake session.** Wrong credentials gave `token: undefined`, which was saved as the text `"undefined"`. After a reload the app treated that as a valid login. Network errors did nothing at all. The login now checks the response and shows a specific message for wrong credentials, too many attempts, network or server problems.
3. **The shift board could go blank.** Any non-list response, such as an expired login, made `shifts.map` crash (`SwapBoard.tsx:5`). Responses are now checked. An expired login returns you to sign-in with a message.
4. **No way to sign out on a shared ward computer.** The login token stayed in `localStorage` and there was no sign-out button, so the next person at that computer could claim shifts as the previous nurse. I added **Sign out**, moved the token to `sessionStorage` (it clears when the browser closes) and removed the old stored token.
5. **Claiming a shift gave no feedback.** Clicking Claim sent the request immediately, with no confirmation, no result, no protection against double clicks, and the shift stayed on the list. Now there's a short confirmation step, a "Claiming…" state, a message when it succeeds, and the shift is removed. If it's already taken (404/409) you're told. If the connection drops you're told the claim may have gone through and to refresh before retrying, and it never retries automatically.
6. **The board didn't fit on phones.** Three fixed 320px columns (`styles.css:1`) meant about 1000px of sideways scrolling. It's now one column on phones and more on wider screens.

**Should-fix**
- **Form labels:** the fields only had placeholder text. They now have visible labels and the right autocomplete settings, so password managers work.
- **Empty and error states:** there was no loading, empty or error message. All three now exist, plus a Refresh button and a last-updated time.
- **Screen readers:** added proper page structure, and each Claim button now says which shift it's for.
- **Keyboard and touch:** visible keyboard focus, and buttons and fields at least 44px tall.
- **Contrast:** colours meet WCAG AA contrast.
- **Dates:** times now show consistently, with duration, overnight end dates, and the time zone they're shown in.

I also made a new `api.ts` file for server calls (timeouts, error handling, checking responses) and `session.ts` for token storage. The README now lists the API contract the app expects and the checks the backend must do.

## What I changed on my own judgement
- **Session length:** because of the `sessionStorage` change, nurses now sign in again after closing the browser.
- **Order:** shifts are sorted by start time.
- **Wording:** "You claimed the … shift" assumes a claim takes effect right away. If a manager has to approve claims, that text needs to change.
- **Time zone:** times use the device's time zone. If the hospital's time zone should always be used, that's a one-line change.
