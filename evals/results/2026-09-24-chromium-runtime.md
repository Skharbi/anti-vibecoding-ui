## Evidence limits

- Firefox-specific behavior;

- full WCAG conformance.

Those are broader compatibility/conformance claims and remain outside this specific six-case execution gate.

## Post-validation correction — independent Claude run

A later independent Claude evaluation (2026-09-24, see `evals/results/2026-09-24-claude-independent.md`) found that two statements in this original record were too strong:

- **G1 original fixture:** the hand-written fixture represented loaded/empty/error content, but did **not** contain a true loading state or an actual retry control. Therefore the original G1 fixture alone did not satisfy the full generation-state requirement.
- **G3 original fixture:** at a smaller 390×400 visible viewport, the focused select could be fully obscured by the fixed action bar. The earlier 390×520 approximation did not expose this failure.
- The original G1–G3 checks rendered repository-authored fixtures rather than UI freshly generated by an agent from the generation prompts.

The independent Claude run subsequently generated G1–G3 outputs and rendered them in Chromium; those generated outputs passed its runtime checks. Treat that later evidence as the corrective/superseding evidence for the generation gates. This note preserves the original test record while making its limitations explicit.
