## What's already right
- **LCP (hero image)** – `app/page.tsx:14` has `priority`, which makes the browser fetch the hero early. It also has a set width and height (1600×900) and `sizes="100vw"`. On desktop and mobile the hero is almost certainly the largest element on screen, and it's set up the right way.
- **CLS** – Every `<Image>` has a width and height, so its space is reserved before it loads. The font comes from `next/font` with `display: "swap"`, which also adjusts the fallback font's size by default, so the font swap causes very little shift. `<Reviews />` is the last thing in `<main>`, so if it grows after loading, nothing on screen moves.
- **Server response time** – `revalidate = 300` means the page is served from cache and rebuilt at most every 5 minutes. The page itself is a server component and sends no JavaScript to the browser.
- **INP** – The page itself has no interactive code, so any risk comes from `Reviews`.
