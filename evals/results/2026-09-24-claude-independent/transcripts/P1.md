- **Impact:** On iOS 17 and 18, line 3 throws `ReferenceError: navigation is not defined` and the whole module stops. No step ever renders and Continue does nothing. Checkout is blocked on part of your mobile traffic.
- **Fix:** Use `history.pushState`, a `popstate` listener and one `render(step)` function. That works in every browser you support. The Navigation API adds nothing this stepper needs, so you don't need a second code path.

**2. The step modules don't exist**

- **Impact:** The import fails. Line 9 has already emptied `#step`, so the user sees a blank area and no error.

**3. Nothing renders when the page first loads**

- **Impact:** Opening `checkout.html` or `?step=shipping` directly, or reloading, shows only a heading and a Continue button.
- **Fix:** When the page loads, call `render()` with the step from the URL, defaulting to `cart`.

**4. Continue on the last step goes to `?step=undefined`**

- **Impact:** The user can't finish the order and lands on an empty page.
