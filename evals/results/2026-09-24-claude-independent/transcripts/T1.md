## final
I fixed the dashboard's spacing and hierarchy. The main cause: the design tokens in `tokens.css` were never imported, so `dashboard.css` used made-up values. Almost every piece of text was 15px/600, spacing values ran from 3px to 41px with no pattern, and all three buttons looked the same. I haven't seen it rendered yet: running a browser needed your approval, so I checked the code only.

**What was wrong**

- **Nothing stood out** (`dashboard.css:9–17`). The title, KPI labels, numbers, trends and section titles were all 15–16px semibold, so the KPI numbers didn't draw the eye.
- **Spacing was random.** Page padding was `13px 22px 7px 30px`, and gaps were 27px between KPIs but 11px below them and 41px before sections. Section titles sat 3px above their content, while list items had 14px margins.
- **All buttons had equal weight.** "New work order" is clearly the main action, but it looked the same as Settings. The title wasn't separated from the buttons either (`gap: 5px`).
- **Some text failed contrast.** `#aaa` is about 2.3:1 and `#888` about 3.5:1, both below the 4.5:1 minimum (WCAG AA) for 15px text.
- **No headings.** Titles were plain `<div>`s and `<span>`s, so a screen reader couldn't tell there were headings.
- **The KPI grid didn't wrap.** It was always 4 columns, which gets crushed on a phone.

**What I changed**

- **Tokens:** `dashboard.css` now imports `tokens.css`, and every size, gap, radius and colour uses a token. I added a few colour tokens that were missing (text, border, surface, accent).
- **Text sizes:**
  - Title 28px.
  - Section headings 20px.
  - KPI numbers 28px with fixed-width digits.
  - KPI labels and trends 13px in the grey `#5f6368` (about 6:1 contrast).
- **Spacing:** 32px between major blocks, 16px inside cards, 12px from a heading to its content, and 24px/16px on screens under 600px.
- **Buttons:** the title sits on the left and the buttons on the right. "New work order" is the filled main button, Export has an outline, and Settings is plain text. All three have a visible keyboard-focus outline and are at least 40px tall.
- **Overdue inspections:** now a bordered list with dividers and a count next to the heading, shown as a number as well as in red. If there are none, it says "No overdue inspections."
- **Structure:** the title is an `h1`, sections use `<section>` with `h2` headings, KPIs use a definition list (`dl`), and buttons have `type="button"`. The grid now wraps from 4 columns down to 2, then 1.

**For you to decide**

- "Recent activity" is still a hardcoded line ("Truck 14 oil change logged by M. Ortiz") that doesn't come from props. That's placeholder data in a live screen. It should become a prop, but that changes the component's interface, so I left it.
- KPI trends stay grey. The trend is a plain string, so the component can't tell whether a change is good or bad. It would need a direction field before it could colour them green or red.
- Inter is listed as the font but never loaded, so browsers without it will use the default sans-serif.

To finish checking, I'd like your approval to run a headless browser and screenshot the page at desktop (1280px), tablet (768px) and phone (360px) widths.
