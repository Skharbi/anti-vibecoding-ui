## What was wrong, most serious first

**Must-fix (now fixed)**
1. **Anyone at a shared ward computer could act as the last nurse who logged in.** The login token was saved in the browser permanently (`App.tsx:6`), there was no sign-out, and an expired session didn't log you out. The next person could claim shifts in someone else's name. Now the token only lasts until the browser is closed, the old saved token is deleted on load, there's a Sign out button, and an expired session returns to the login screen with a message.
2. **A failed login still logged you in.** `Login.tsx:8` never checked the server's response, so a wrong password saved the text `"undefined"` as the token and opened a board that couldn't load. It also didn't tell the server it was sending JSON. Now a failed login shows a clear message: wrong credentials, too many attempts (429), or can't reach the server.
3. **You couldn't log in with the keyboard.** "Log in" wasn't a real button, the fields had no labels (only placeholder text), and pressing Enter did nothing. It's now a proper form with labels, password-manager support, and errors that screen readers announce.
4. **Claiming a shift gave no feedback at all.** One click sent the claim with no confirmation, no success or error message, no protection against double-clicks, and the shift stayed on the list. Now:
   - Claiming takes two steps (Claim, then Confirm, with Escape to cancel).
   - The shift disappears on success and a message is announced.
   - If someone else already took it (404/409/410), it's removed with an explanation.
   - A 403 shows "You can't claim this shift."
   - If the result is unclear (network error), the list refreshes and you're asked to check before trying again, rather than inviting a second claim.
5. **The board didn't work on phones.** The layout was fixed at three 320px columns, so it scrolled sideways on mobile. It now adapts to the screen width, and buttons are at least 44px tall for touch.
6. **Loading, errors and "no shifts" all showed as a blank page.** There are now separate states for loading, failed to load (with Try again), no open shifts, and "couldn't refresh, showing the last list".

**Should-fix (now fixed)**
- Shift times were shown with seconds and the full date twice. Now it reads like "Tue 3 Mar · 19:00–07:30 (ends Wed 4 Mar)", with the length in hours, sorted soonest first.
- The page structure is now proper headings and a list. Each Claim button names its shift for screen readers, and keyboard focus goes somewhere sensible after a claim.
- If the server sends malformed shift data, the bad entries are skipped instead of crashing the page.
- Loading the list can no longer overwrite itself with an older result. I removed an unused import, and added colour tokens, visible keyboard focus and dark mode.
