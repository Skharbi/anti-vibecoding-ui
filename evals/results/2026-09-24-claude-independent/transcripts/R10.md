## Must-fix

**1. Both axes hide their labels, so the chart can't be read**
Evidence: `src/RevenueChart.tsx:11-12`, where `tick={false}` is set on both `XAxis` and `YAxis`.
Impact: Nothing shows which month a point belongs to or what a line's height means. The only way to get a number is to hover over each point, one at a time. Nobody can compare months at a glance.
Fix: Turn the ticks back on. Format Y values as currency in short form ($120K). On narrow screens, set `minTickGap` or `interval="preserveStartEnd"` so month labels don't overlap.
Verify: At 360px and at desktop width, each month label and at least three Y values are readable without hovering.

**2. The Y axis starts at a hidden, fixed 80,000, which exaggerates the gap between the lines**
Evidence: `:12` sets `domain={[80000, "auto"]}` and hides the ticks.
Impact: A 5% miss against target can look like a collapse, and the reader can't tell the scale was cut because no Y labels are shown. The 80,000 cutoff is also hard-coded. It fits one dataset and will be wrong for other date ranges or accounts.
Fix: Use `domain={[0, "auto"]}`. If you want a zoomed-in view on purpose, work out the lower bound from the data and make sure the Y labels (from #1) are visible so the cutoff is obvious.
Verify: Test with actual = 95K and target = 100K. The lines should look about 5% apart, not far apart.

**3. The two lines differ only by color: green versus red, with no legend**
Evidence: `:14-15`. There's no `<Legend>`, the lines have the same style, and they use `#16a34a` and `#dc2626`.
Impact: Nothing says which line is actual and which is target. Red and green are the pair people with color vision deficiency most often can't tell apart. Red also usually means "bad", but here it marks the target, so the colors send the wrong signal.
Fix: Add a legend or direct labels with readable names (`name="Actual"` and `name="Target"`). Draw the target as a dashed line in a neutral color. Show the actual line solid and in the stronger color.
Verify: Check in a grayscale or deuteranopia simulation that the two series are still easy to tell apart.

**4. The data is invisible to screen readers and keyboard users**
Evidence: The SVG has no accessible name. There's no text or table version. The `<Tooltip />` at `:13` is the only way to read values, and it only appears on mouse hover.
Impact: Screen-reader users get "Revenue" and nothing else. Keyboard users can't reach any values.
Fix: Give the chart an accessible name and a short summary, for example "Revenue vs target, Jan–Jun 2026: $412K actual, 6% below target". Add a visually hidden `<table>` or a "View as table" toggle. On Recharts 2.x, also set `accessibilityLayer`; it's on by default in 3.x.
Verify: Tab to the chart, and read it with VoiceOver or NVDA.

import { LineChart, Line, XAxis, YAxis, Tooltip, Legend, ResponsiveContainer, CartesianGrid } from "recharts";

type Point = { month: string; actual: number; target: number };

const usd = new Intl.NumberFormat("en-US", { style: "currency", currency: "USD", maximumFractionDigits: 0 });
const usdShort = new Intl.NumberFormat("en-US", { style: "currency", currency: "USD", notation: "compact" });

export function RevenueChart({ data, title = "Revenue vs target" }: { data: Point[]; title?: string }) {
  if (data.length === 0) {
    return (
      <div className="chart-card">
        <h3>{title}</h3>
        <p>No revenue recorded for this period.</p>
      </div>
    );
  }
  return (
    <div className="chart-card">
      <h3 id="revenue-chart-title">{title}</h3>
      <ResponsiveContainer width="100%" height={280}>
        <LineChart data={data} accessibilityLayer aria-labelledby="revenue-chart-title">
          <CartesianGrid vertical={false} strokeOpacity={0.15} />
          <XAxis dataKey="month" minTickGap={16} />
          <YAxis domain={[0, "auto"]} tickFormatter={(v) => usdShort.format(v)} width={56} />
          <Tooltip formatter={(v: number) => usd.format(v)} />
          <Legend />
          <Line name="Actual" dataKey="actual" stroke="#2563eb" strokeWidth={2} dot={{ r: 3 }} />
          <Line name="Target" dataKey="target" stroke="#6b7280" strokeDasharray="5 4" dot={false} />
        </LineChart>
      </ResponsiveContainer>
      {/* + visually hidden <table> with the same rows (fix 4) */}
    </div>
  );
}
