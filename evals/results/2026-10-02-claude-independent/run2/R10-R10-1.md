# Review: `src/RevenueChart.tsx`

I read the component's code only. I didn't render it, and I didn't inspect the `.chart-card` styles or check the Recharts version. Anything that depends on those is marked as unverified.

The chart plots actual revenue against a target over time. The main problem is that it gives the reader no way to read a value without hovering.

## Must-fix (confirmed in code)

1. **Both axes have no labels** (`:11`, `:12`). `tick={false}` removes every month and every amount, so the chart has no scale. The only way to get a number is the hover tooltip. That excludes keyboard and touch users, and nobody can scan the chart. Restore ticks, with months on X and currency-formatted amounts on Y (e.g. `$120k`).

2. **The Y axis is truncated and hidden** (`:12`). `domain={[80000, "auto"]}` starts the baseline at 80k. Truncation can be acceptable on a line chart, but with the ticks hidden the reader can't tell the baseline isn't zero. Small gaps between actual and target look large. Either show the ticks so the truncation is visible, or derive the domain from the data. The hardcoded 80000 will also clip any month that falls below it.

3. **Series are identified by color alone, and there's no legend** (`:14`, `:15`). Nothing says which line is "actual" and which is "target". The two colors are green `#16a34a` and red `#dc2626`, which are the classic pair people with red-green color blindness can't tell apart. Add a legend. Direct-label the line ends, since two series is few enough. Give the target a non-color cue such as a dashed stroke.

4. **The colors imply good and bad.** Red usually means "bad", but a target is a reference line, not a failure state. The two lines also have identical weight, so the target competes with the actual line. Make actual the strong series and target a thinner, dashed, muted line. I haven't run the dataviz palette validator on these hexes. The green may also fall below 3:1 contrast on a white surface, but that is from memory and unverified.

5. **No loading, empty or error states.** If `data` is empty or still loading, the component renders a blank axis-less box with no explanation. Handle those cases explicitly.

## Should-fix

6. **The tooltip shows raw output.** `<Tooltip />` is unformatted. It will show the lowercase keys `actual` and `target` and unformatted numbers. Pass `name="Actual"` and `name="Target"` to the `Line` components, and use a currency `formatter`. A tooltip that also shows the variance would help.

7. **There's no accessible alternative.** There is no description of the chart's takeaway and no data-table view. Recharts 3 enables `accessibilityLayer` by default, but v2 needs it set explicitly. I'd need to check the installed version. Either way, a "View as table" toggle or a summary line, such as "Revenue is 4% below target in September", would help. The bare `<h3>Revenue</h3>` also gives no unit or period. Something like "Monthly revenue vs target, USD" is better, and the heading level should fit the surrounding page.

8. **`type="monotone"` smooths the lines.** It can draw curves that overshoot between points, implying values that aren't in the data. For financial figures, `type="linear"` is more honest. This is a judgment call.

9. **There are no point markers** (`dot={false}`). With monthly data, the individual points are the real data and the line between them is interpolation. Small markers would show that, and they give the hover a target.
