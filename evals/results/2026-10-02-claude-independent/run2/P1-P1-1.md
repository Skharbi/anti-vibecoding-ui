**[Must-fix] The Navigation API breaks the stepper on iOS Safari 17 to 26.1**
- Evidence: `src/checkoutStepper.js:3` calls `navigation.addEventListener` at module top level with no feature check. Per [web.dev](https://web.dev/blog/baseline-navigation-api) and [InfoQ](https://www.infoq.com/news/2026/05/navigation-api-browser/), Safari support starts at 26.2, and Firefox at 147. These are search summaries, not MDN or caniuse, which I couldn't reach. Please confirm the versions against caniuse before you decide on the fix.
- Impact: on iOS Safari 17 to 26.1, `navigation` is undefined and the module throws a `ReferenceError`. The click handler at line 16 is never attached, so Continue does nothing and checkout is blocked. Your support policy includes those versions, and iOS browsers all run on WebKit, so the problem applies to every iOS browser.
- Fix: guard with `if ("navigation" in window)`. In the fallback, use `history.pushState` plus `popstate` and one shared `showStep(step)` function. You can also use plain links or form navigation (`?step=` as a real page load). The fallback is also what you get if Navigation API support turns out to be narrower than reported.
- Verify: test on real iOS Safari 17 or 18, or BrowserStack. Confirm that Continue, Back and reload all work.

**[Must-fix] Nothing renders on first load or reload**
- Evidence: the `navigate` event only fires on navigations after the page loads, not on the initial load. `#step` starts empty in `checkout.html:2`, and nothing in the script renders the current step at startup.
- Impact: opening `/checkout.html` or reloading `?step=payment` shows only a heading and a Continue button. Continue then goes to the step after the one in the URL (`cart`'s successor, `shipping`, when no step is set), so the user never sees the cart.
- Fix: extract `showStep(step)`, call it once at startup with the step from the URL (default `cart`), and call it again from the `navigate` handler.
- Verify: load each `?step=` URL directly and reload it. The matching step should appear each time.
