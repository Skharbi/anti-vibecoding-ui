Any server that selects its body parser by content type won't parse it as JSON. A server that was written to accept `text/plain` is the only case where this works. This may be deliberate, for example to avoid a CORS preflight. If so, it needs a comment, because it also gives up the preflight check. I'd rate it should-fix.
