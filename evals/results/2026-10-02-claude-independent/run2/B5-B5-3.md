## Confirmed issues

These come from reading the code. I haven't checked what the logging endpoint stores.

1. **Card data goes to a third-party log service.**
   - `PaymentForm.tsx:7` passes the whole `values` object (`cardNumber`, `cvc`, `amount`) as `input`.
   - `errorReporting.ts:12` serializes it and sends it to `logs.example-observability.io`.
   - This is the most serious problem. Sending a CVC off-site is also a PCI DSS concern. I haven't verified the exact PCI requirement.
2. **The session access token is sent in telemetry** (`errorReporting.ts:13`). Anyone with access to the logs could use it to take over a session.
3. **The user's email is sent unnecessarily** (`errorReporting.ts:14`). Use an opaque ID if you need to correlate reports.
4. **The full `location.href` is sent** (`errorReporting.ts:15`). Query strings and fragments often carry tokens, reset codes, or PII.
5. **Error messages and stacks are sent unscrubbed.** They can echo user input.
6. **The `fetch` has no `.catch`.** A failed report becomes an unhandled rejection, and the reporter can throw synchronously, for example if `JSON.stringify` hits a circular `input`.
7. **Cookies may be sent with the report.** The call doesn't set `credentials`, and the default depends on whether the endpoint is same-origin.

## Proposed fix

**`src/errorReporting.ts`:**
- Drop `token`, `userEmail`, and the free-form `input` field.
- Replace `input` with a `meta` object that only allows string, number, boolean, or null values.
- Run message, stack, and string meta values through a `scrub()` function. It redacts card-like digit runs, emails, Bearer tokens, JWTs, and `token=`/`code=`/`password=` query values, and truncates to 2000 characters.
- Send only `origin + pathname` as the URL.
- Set `credentials: "omit"` and a JSON `Content-Type`.
- Add `.catch(() => {})` and wrap the whole function in `try/catch` so reporting can never throw into the app.
- Add `name` and `ts` fields.

**`src/PaymentForm.tsx`:**
- Call `reportError(e, { action: "submitPayment", meta: { status: ... } })`.
- Never pass `values`.
