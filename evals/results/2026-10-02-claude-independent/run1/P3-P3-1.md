## Must-fix

**1. The page is blocked from search**
- Evidence: `app/pricing/layout.tsx:2` sets `robots: { index: false, follow: false }`. `README.md` says `/pricing` is a public page "we want people to find through search."
- Impact: the page tells search engines not to index it, which contradicts the stated goal.
- Fix: remove the `robots` entry, or set `index: true`.
- Verify: view the rendered `<meta name="robots">` and check the `X-Robots-Tag` header on the deployed URL. Then run URL Inspection in Search Console.

**2. Nothing shows if the plans request fails or is slow**
- Evidence: `app/pricing/page.tsx:8` calls `fetch(...).then(r => r.json()).then(setPlans)` with no `res.ok` check and no `.catch`. The initial state is `[]`, and there is no loading, empty or error UI.
- Impact: while loading, or after a failed request, the visitor sees only "Pricing" and the nav. A failure also throws an unhandled promise rejection, and an error body that isn't a plan array could crash `plans.map`.
- Fix: render plans on the server. Make the page a server component, or fetch in a server component and pass the result down. Then handle error and empty states explicitly. If you keep client fetching, add the loading, error and retry states and validate that the response is an array.
- Verify: block or 500 `/api/plans` and confirm the page shows a clear message. Load the page with JavaScript disabled and confirm the plans are in the HTML.

**3. The nav can't be used from the keyboard and isn't crawlable**
- Evidence: `page.tsx:13-15` uses `<span onClick={() => router.push(...)}>`.
- Impact: spans can't be tabbed to or activated with Enter. Screen readers don't announce them as links. Middle-click and "open in new tab" don't work. Crawlers can't follow them, which also hurts discoverability.
- Fix: use `next/link` (`<Link href="/features">`) inside `<nav aria-label="Main">`. That also removes the need for `useRouter` and `"use client"` for navigation.
- Verify: tab to each link, press Enter, and confirm the destination is a real `href`.
