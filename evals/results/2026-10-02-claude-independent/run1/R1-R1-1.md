# Samplyr landing page review

**Verdict: Fail. Do not launch yet.** I read `index.html` and `style.css` in full. I did not render the page in a browser, so the responsive and contrast notes come from the code and my own arithmetic.

## Must-fix (confirmed in code)

**1. The Subscribe button is a `<div>`, so keyboard and screen-reader users can't use it**
- Evidence: `index.html:21` has `<div class="pill" onclick="subscribe()">`.
- Impact: it can't be reached with Tab and has no button role. Pressing Enter in the email field does nothing.
- Fix: use `<button type="submit">`.
- Verify: tab to the button and submit with Enter.

**2. The signup form reports success but captures nothing**
- Evidence: `index.html:23` is `function subscribe(){ alert('Subscribed!'); }`. There is no `action`, no `fetch`, and the email value is never read.
- Impact: every visitor is told they subscribed and none are. This is lost leads plus false feedback.
- Fix: post the email to a real endpoint. Add a pending state, inline success and error messages (announced with `role="status"`), `required`, and `autocomplete="email"`. Replace the `alert`.
- Verify: submit a valid email, an invalid email and a failed request, then confirm the address arrives.

**3. The email input has no label**
- Evidence: `index.html:21` uses only `placeholder="Your email"`.
- Impact: there is no accessible name once the placeholder disappears.
- Fix: add a visible `<label for>`.

**4. There is no viewport meta tag, and the layout has no breakpoints**
- Evidence: `index.html:3` has no `<meta name="viewport">`. `style.css` has no `@media` rules. It sets a fixed 72px h1 (line 5), 64px side margins and 48px card padding, and `repeat(3,1fr)` on the feature grid (line 8).
- Impact: phones render a zoomed-out desktop page. With the tag added, the cards would still be cramped and the headline would overflow.
- Fix: add the viewport tag. Use `clamp()` for the h1, make the grid collapse to one column on narrow screens, and reduce the side padding.
- Verify: check at 390px, 768px and 1280px.

**5. The "Pricing" nav link goes nowhere**
- Evidence: `index.html:5` links to `#pricing`, but no element has `id="pricing"`.
- Fix: add a pricing section or remove the link.

  - Lead with the real job, for example tracking samples, locations, freezer inventory, chain of custody and who handled what.

  - Use the actual action as the CTA label.
  - I'd write the specifics with you, since I'd only be guessing at the features.
- **Contrast looks low (my arithmetic, not a rendered check).**
  - Body text is `rgba(255,255,255,.6)` on the blue-purple gradient (`style.css:12`). Against `#2563eb` I get roughly 2.7:1, under the 4.5:1 AA minimum.
  - Nav links at .7 opacity (`style.css:3`) are borderline.
  - White 16px text on the `#3b82f6` end of the pill gradient is also under 4.5:1.
  - Verify with a contrast tool.
- **Generic AI-template styling throughout.** This is a judgment call, but it hurts credibility with lab managers.
  - Purple-to-blue page gradient, gradient headline text, glassmorphism cards with glow, and 32px-radius cards nested inside a card.
  - Pill buttons with arrows, and an emoji icon trio (⚡🔒✨) with filler copy.
  - A flat, light, high-contrast design with real product content would suit the audience better.
