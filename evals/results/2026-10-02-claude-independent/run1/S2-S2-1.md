## Must-fix

**[Must-fix] Untrusted Markdown is rendered as raw HTML with no sanitization**
Evidence: `src/Comment.tsx:6` and `src/Comment.tsx:10`. `marked.parse(comment.body)` is passed straight into `dangerouslySetInnerHTML`. `CommentForm.tsx:2-9` shows the body is free-form user input.
Impact: `marked` passes inline HTML through unchanged, so a comment like `<img src=x onerror=...>` or `[x](javascript:...)` can run script in every viewer's session. This is stored XSS, which can hijack sessions or act as the viewer. The "Markdown supported" label invites this kind of input.
Trust boundary: the comment author's input reaches other users' browsers. Whether the backend sanitizes the body is unverified, but the client shouldn't rely on that.
Fix: sanitize the parsed HTML before rendering, for example with DOMPurify using an allowlist of tags and attributes. Force `rel="noopener noreferrer nofollow"` on links, and decide whether to allow images at all. Images are a tracking and privacy vector. A CSP is defense-in-depth, not a replacement.
Verify: render comments containing `<script>`, `<img onerror>`, `javascript:` links and `<iframe>`. Confirm none execute and the markup is stripped.

## Should-fix

**Form can lose the user's text on failure** (`CommentForm.tsx:5`)
`setBody("")` runs immediately after `onPost(body)`. `onPost` returns `void`, so there is no way to know the post succeeded. If the request fails, the comment is gone. Make `onPost` return a Promise, clear only on success, and show an error with retry.

**No pending, error or success state, and no duplicate-submit guard** (`CommentForm.tsx:5-8`)
The button stays active while a request is in flight, so a double click can post twice. Disable it, or set `aria-busy`, while pending. Announce the result in a live region (`role="status"` for success, `role="alert"` for errors).

**Empty and whitespace-only comments can be submitted** (`CommentForm.tsx:5`)
Trim the body and block empty posts with an inline message tied to the textarea via `aria-describedby`. Add a length limit to match the server's, and show a counter if the limit is tight. The server must still validate.

**Hardcoded `id="c"`** (`CommentForm.tsx:6-7`)
The id collides if the form appears twice, for example in reply threads. Use `useId()`.

**Raw ISO timestamp shown to users** (`Comment.tsx:9`)
Users see `2026-10-02T14:03:00Z`. Format it with `Intl.DateTimeFormat`, setting the timezone and locale explicitly. Keep the ISO value in `dateTime`, and consider a relative label with the absolute time in a `title` or tooltip.

**Parse runs on every render, and the type cast hides a risk** (`Comment.tsx:6`)
`marked.parse(...) as string` suppresses the `string | Promise<string>` return type. Memoize with `useMemo` on `comment.body`. Parsing and sanitizing every comment on every render adds up in long lists.
