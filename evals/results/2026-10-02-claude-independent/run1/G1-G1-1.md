## Final output

I built the dashboard as plain HTML, CSS and JS with no build step or dependencies. I haven't opened it in a real browser because none is installed here. So the layout, mobile widths, dark-mode contrast and tooltip placement are unchecked by eye.

I did check the logic in jsdom. It renders the four KPI tiles, the chart's two lines, 11 bars and 8 product rows. Arrow-key navigation produces the correct screen-reader readout. A simulated load failure shows the error banner, and Retry recovers from it.

**What it is:** analytics for "Fernhill Goods", a made-up online homeware shop, since you didn't name a product. Say if you want a different one. The data is generated in the browser and labeled "Sample data" in the toolbar, so nothing in it passes as real.

**Contents:**
- **Filters:** period (7, 30 or 90 days) and channel, both native selects, plus a "Clear filters" button that appears when they differ from the defaults.
- **KPI row:** revenue, orders, conversion rate and average order value. Each has a change against the previous equal period, shown with an arrow and sign as well as color, and a sparkline.
- **Daily trend chart:** a metric switch for revenue, orders or sessions, with this period against the previous one. Hover, tap or arrow-key through days for a tooltip, and "View as table" gives a text version.
- **Revenue by channel and purchase funnel:** horizontal bars, with the share or step-to-step continuation rate beside each.
- **Products table:** sortable columns exposed to assistive tech. On a phone it drops the Category, Units and Share columns.
- **Other:**
  - Light and dark themes with an Auto/Light/Dark toggle.
  - A skip link and visible focus outlines.
  - Reduced-motion and forced-colors rules.
  - A refresh keeps the old figures dimmed while new ones load, and a late response can't overwrite a newer selection.
  - Amounts are US dollars and dates are UTC.

**Design choices:**
- It has no card-grid, gradient or glow styling. The KPIs are one ruled strip, and there is a single accent blue plus gray.
- The chart colors come from the validated palette. The two-line comparison uses blue for this period and a dashed gray for the previous one, so it doesn't rely on color alone.
- There is only an Overview page, with no navigation to pages that don't exist.

**Not covered:** the data is never fetched from a server, so real API behavior, authentication and caching aren't tested. You can see the error and retry path by loading `index.html?simulate=error`.
