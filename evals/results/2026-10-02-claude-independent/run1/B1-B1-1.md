## What I fixed

**Must-fix, all confirmed in the original code**
- **Login button wasn't a button** (`Login.tsx:8`). It was a `<div onClick>`, so it couldn't be reached by keyboard, Enter didn't submit, and screen readers didn't see it as a control. It's now a `<form>` with a real submit button.
- **Login had no feedback and could crash.**
  - A failed login called `r.json().token` with no `ok` check, so a wrong password gave an unhandled error and no message.
  - Double clicks fired duplicate requests.
  - It now shows a pending state, an inline error announced as an alert, and clears the password on failure.
- **Inputs had only placeholders** (`Login.tsx:6-7`). They now have real labels and `autocomplete` values, so password managers work.
- **Claim failed silently** (`SwapBoard.tsx:6`). The response was never checked, and there was no confirmation, no error, and no double-click guard.
  - It now disables the button per shift while claiming and removes the shift on success.
  - It announces success or failure in a live region, and treats 404/409 as "no longer available" and refreshes.
- **Loading the board had no error, loading or empty state** (`SwapBoard.tsx:5`). A failed request left a blank page. It now has loading, empty, error and retry states. The fetch is aborted on unmount, which removes a stale-response race.
- **Expired sessions weren't handled.** A 401 now logs the user out with a message. I added a Log out button, because there was no way to sign out.
- **The 3×320px grid forced horizontal scroll below about 1000px** (`styles.css:1`). It's now `auto-fill, minmax(min(100%, 280px), 1fr)`.

**Should-fix**
- **Structure and semantics:**
  - Added `main` and `header` landmarks and `h1`/`h2` headings.
  - The shifts are now a list.
  - Times use `<time>` with a compact, explicit format.
  - Claim buttons are named by ward and time.
- **Styling:** 44px touch targets, a visible `:focus-visible` ring, colour tokens, error colour with a text cue, reduced-motion support, and long text wraps.
- **New `src/api.ts`:**
  - One fetch wrapper with a 15s timeout, `ok` checks, network and bad-JSON errors, and a `Content-Type: application/json` header on the login request, which was missing.
  - Unused `useEffect` import removed, and `localStorage` access wrapped so private mode doesn't crash.
  - `styles.css` was never imported anywhere; `App.tsx` now imports it.
