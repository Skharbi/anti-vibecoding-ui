# Code of Conduct

## Expected behavior

Contributors and maintainers should:
- discuss ideas and defects respectfully;
- critique code, evidence, and behavior rather than people;
- distinguish objective failures from design preferences;
- give enough context for others to reproduce a finding;
- avoid publishing secrets, private data, or exploit details in public discussion;
- accept that reasonable product/design tradeoffs may differ.

## Unacceptable behavior

Do not use harassment, discriminatory language, personal attacks, threats, doxxing, spam, or deliberate disclosure of private/security-sensitive information.

## Moderation

Repository maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when necessary to protect contributors or the project.

## Scope

These expectations apply to repository discussions, issues, pull requests, and other project-maintained collaboration spaces.
